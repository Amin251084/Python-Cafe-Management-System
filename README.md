# Cafe Management System ☕

A simple Cafe Management System developed using Python.

## Features

- Display cafe menu
- Create new orders
- Add multiple quantities of products
- View current orders
- Remove products or reduce their quantities
- Calculate total prices
- Apply discounts to orders
- Generate invoices

## Technologies Used

- Python
- Dictionaries
- Lists
- Functions
- Loops
- Conditional Statements
- Modules

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the main.py file.
